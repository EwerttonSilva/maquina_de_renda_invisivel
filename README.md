# Landing Page - Máquina de Renda Invisível

Esta é uma landing page responsiva para o infoproduto "Máquina de Renda Invisível", um ebook sobre como gerar renda online automática.

## Arquivos incluidos

- `index.html` - Página principal da landing page
- `style.css` - Estilos CSS para a página
- `README.md` - Este arquivo

## Características

- Design moderno e responsivo
- Otimizado para conversão
- Seções incluindo:
  - Header com chamada para ação
  - Identificação de problemas
  - Apresentação da solução
  - Benefícios do produto
  - Sobre o autor
  - Depoimentos
  - Tabela de preços com garantia
  - FAQ
  - Footer

## Tecnologias usadas

- HTML5
- CSS3 (com Flexbox e Grid)
- JavaScript vanilla para funcionalidade do FAQ
- Google Fonts (Poppins)

## Como usar

1. Abra o arquivo `index.html` em qualquer navegador moderno
2. Personalize o conteúdo conforme necessário:
   - Substitua as imagens placeholder por imagens reais
   - Atualize o texto com informações específicas do seu produto
   - Ajuste cores e estilos no `style.css` se necessário
   - Configure os links de chamada para ação para apontarem para sua plataforma de pagamento

## Personalização

Para personalizar esta landing page:

### Cores
As cores principais estão definidas no início do CSS:
- Primária: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
- Secundária: varie conforme necessário nas classes

### Conteúdo
- Substitua o texto ao longo do HTML
- Atualize os depoimentos com feedback real dos clientes
- Modifique a seção sobre o autor com suas informações
- Ajuste os benefícios conforme o conteúdo real do seu ebook

### Funcionalidade
- O FAQ já possui funcionalidade de abrir/fechar com JavaScript puro
- Os botões de CTA atualmente apontam para "#" - substitua pelos seus links reais# maquinaRendaInvisivel
